# Exercises — Written Drills

This directory contains handwritten first-attempt drills and their corrections.

## Naming Convention
- `release-baseline-w01-w04.pdf` — Release-day baseline diagnostic
- `wXX-first-attempt.pdf` — Handwritten first attempt (scan/photo)
- `wXX-corrections.md` — Corrections with citations after review

## Rules
- First attempt: NO code, NO Internet, NO AI
- Upload/commit first attempt BEFORE checking notes
- Never replace or delete the first attempt
- Each drill: 4 short subquestions in sample-final style
