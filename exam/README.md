# Exam Preparation Materials

This directory contains exam preparation artifacts.

## Files
- `a4-notes-part1-midterm.pdf` — Living two-A4 exam sheet (Part I, for midterm)
- `midterm-reflection.md` — Post-midterm error/reflection note (within 72h of exam)
- `a4-notes-part2-final.pdf` — Living two-A4 exam sheet (final version)
- `mock-final-first-attempt.pdf` — 90-minute mock final (untouched first attempt)
- `mock-final-corrections.md` — Self-marking and corrections with links to weekly posts

## Two-A4 Exam Sheet Guidelines
- Contains: definitions, canonical equations, algorithm steps, comparison tables, tiny worked examples
- NOT copied prose
- The compression process is itself a learning exercise
- Part I version due 14 Oct 2026
- Part II/final version due 2 days before final exam
